# EVE Assistant

EVE is a local AI voice assistant focused on engineering workflows.

Current Features

- GPU accelerated F5-TTS voice synthesis
- Custom voice cloning
- Modular Python architecture
- Local speech synthesis
- NVIDIA CUDA support
- Windows development environment

Roadmap

- Speech-to-text
- LLM integration
- Memory
- Vision
- Tool calling
- Wake word
- Raspberry Pi deployment

Tech Stack

- Python 3.11
- PyTorch
- CUDA
- F5-TTS
- Faster Whisper
- FFmpeg
- TorchCodec
